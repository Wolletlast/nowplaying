# NowPlaying: плеер телефона на ПК

Две программы работают вместе:

- **NowPlaying.exe** (ПК): карточка в правом верхнем углу с вращающейся пластинкой, ползунком и кнопками. Кнопки управляют плеером на телефоне.
- **NowPlaying.apk** (Android): отправляет на ПК трек, обложку и позицию и выполняет команды с ПК. Телефон сам находит ПК в Wi-Fi сети, вводить IP не нужно.

Звук идёт с телефона на ПК через AudioRelay (бесплатно) и играет в наушники ПК.

## Как получить exe и apk без Android Studio

Файлы собирает бесплатный облачный сервис GitHub Actions. Один раз:

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (можно приватный).
2. Распакуйте архив и загрузите в репозиторий всё содержимое папки `nowplaying` (Add file → Upload files, перетащите папки `.github`, `android`, `pc` и файл README.md).
3. Откройте вкладку **Actions**, выберите **Build NowPlaying** → **Run workflow**. Сборка идёт около 5-10 минут.
4. Когда появится зелёная галочка, откройте запуск и внизу, в блоке Artifacts, скачайте **NowPlaying-Windows** (внутри NowPlaying.exe) и **NowPlaying-Android** (внутри NowPlaying.apk).

Если сборка упала (красный крестик), откройте её лог и пришлите мне ошибку, я исправлю.

Чтобы файлы лежали на странице Releases и скачивались по прямой ссылке (удобно качать apk прямо с телефона), создайте в репозитории тег, например `v1`.

## Установка

**ПК:** запустите NowPlaying.exe. Windows SmartScreen может предупредить, потому что программа не подписана: «Подробнее» → «Выполнить в любом случае». Разрешите доступ в брандмауэре для частных сетей.

**Телефон:** установите NowPlaying.apk (разрешите установку из этого источника). Откройте приложение:
1. «Доступ к уведомлениям»: включите NowPlaying. Если Android пишет «ограниченная настройка»: Настройки → Приложения → NowPlaying → ⋮ → «Разрешить ограниченные настройки».
2. «Не засыпать (батарея)»: выберите «Не ограничивать» для приложения.
3. «Проверить связь»: на ПК появится карточка. Телефон и ПК должны быть в одной Wi-Fi сети. Если автопоиск не сработал (например, в сети включена изоляция клиентов), введите IP ПК вручную.

**Звук (AudioRelay, audiorelay.net):** установите AudioRelay на ПК и на телефон (Android 10 или новее). На телефоне откройте вкладку Server и выберите источник Apps, разрешите запросы. На ПК откройте вкладку Player и нажмите на свой телефон в списке серверов. Включите музыку на телефоне: звук пойдёт на ПК. Наушники сделайте устройством вывода по умолчанию в Windows. Некоторые приложения запрещают запись своего звука, тогда звук не пойдёт.

## Карточка на ПК

По умолчанию в правом верхнем углу. Её можно перетащить мышью. Шестерёнка на карточке (или «Настройки…» в трее) открывает окно настроек.

### Источник музыки

В настройках выберите, что показывает карточка:

- **Автоматически** — то, что играет сейчас (телефон или приложение на ПК; побеждает то, что запустили позже).
- **Телефон** — трек с телефона, кнопки управляют телефоном.
- **Приложение на ПК** — любой плеер или браузер с медиа-управлением Windows (Spotify, Яндекс Музыка, YouTube в браузере и т. д.). Работают обложка, перемотка, пауза, следующий и предыдущий. Лайк недоступен.
- **Окно** — карточка показывает название выбранного окна. Кнопок управления для окна нет.

Надпись над названием трека показывает, откуда он: «Телефон · …», «ПК · …», «Окно · …». Если выбранный источник пропал (закрыли приложение), карточка пишет «Источник недоступен».

### Вывод звука на ПК

В настройках есть список устройств вывода Windows. Нажмите на нужное, и оно станет устройством по умолчанию (на него играет AudioRelay и большинство программ). Если переключить не вышло, кнопки «Параметры звука Windows» и «Громкость приложений» откроют системные окна, где устройство можно назначить вручную, в том числе отдельному приложению.

### Вид

Положение (4 угла), размер, прозрачность, вращение пластинки, автоскрытие, автозапуск с Windows. Значок в трее: показать или скрыть, настройки, выход. Карточка прячется, когда музыка не играет (отключается в настройках).

## Что важно знать

- **Лайк** работает у плееров, которые показывают кнопку лайка в уведомлении (Яндекс Музыка, Spotify и др.). Иначе сердечко неактивно.
- **Перемотка** работает, если плеер её поддерживает.
- Команды с ПК доходят до телефона почти мгновенно.
- Данные ходят только по вашей локальной сети. Управление и настройки доступны только с самого ПК.
- Приложения, окна и вывод звука ПК работают через встроенный PowerShell Windows 10 (1809) и новее, ничего ставить не нужно. Если на вашем ПК что-то из этого не заработает, в настройках будет написана причина.
- Порты: 8765 (TCP) и 8766 (UDP, автопоиск).

## Запуск из исходников (для разработки)

ПК: установите Node.js, затем `pc/start.bat` (Electron ставится сам). Отладка без окна: `cd pc && node server.js`, интерфейс на http://127.0.0.1:8765.
